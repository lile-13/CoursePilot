# CoursePilot 课表助手

个人课表与课程作业管理系统。面向在校大学生，用于把学校教务系统中的课表导入到本地，按周查看课程、节次与教室，并集中管理各门课程的作业截止时间和完成状态。

项目使用 React + Vite 和 Electron。桌面版使用随软件提供的 SQLite 保存课程、作业与设置，无需安装数据库服务器；浏览器版使用 localStorage。关闭后重新打开数据仍然保留。数据库初始化、旧数据迁移与备份说明见 [SQLite存储说明](docs/SQLite存储说明.md)。

## 功能清单

- **北京时间与学期周次**：以北京时间（UTC+8）为准显示当前日期、星期和实时时钟；根据设置的“第一周起始日”自动计算当前教学周与单双周。起始日可以是周日或任意星期，课表会从该天开始排列一周，不受电脑本地时区影响。
- **本地多用户账号（桌面版）**：首次启动创建本地账号，密码使用 scrypt 加盐哈希保存；每个账号拥有独立的 SQLite 课表与作业，登录状态会保留，可在设置中退出登录并切换账号。
- **寻路入口**：顶部“寻路”按钮在默认浏览器中打开 `pathly.top`。
- **课表导入（先预览、后保存）**：
  - 东北大学一键导入：点击按钮打开学校教务系统，登录后进入“我的课表”，点击页面右下角注入的“导入课表到 CoursePilot”按钮，课表页面自动回传并进入预览。
  - 上传 HTML 文件：在教务课表页按 `Ctrl+S`（macOS 为 `⌘+S`）保存为“网页，仅 HTML”后上传。
  - 粘贴页面源码：直接粘贴课表页的 HTML。
  - 书签采集：把页面提供的“采集课表”按钮拖到浏览器书签栏，在课表页点击即可复制源码。
  - 解析后进入预览表格，可逐行修改课程名、教师、类型、星期、节次、周次、教室，支持合并导入或覆盖导入。
- **今日视图**：默认首页汇总当天日期、星期、教学周和单双周；显示正在上的课或下一节课的倒计时、今日全部课程及“已结束 / 上课中 / 即将开始”状态，并列出最近截止的待交作业。
- **周课表视图**：按星期与节次展示课程块，显示教室、教师和节次；支持周次切换、单双周、任意周次范围、实验课标记、同一时段多门课程并排显示、当前时间正在上的课程高亮。
- **课程管理**：新增、编辑、删除课程；一门课程可配置多个上课时间段，每个时间段可单独设置教室和周次；提供 8 种课程配色。
- **作业管理**：新增、修改、删除作业；关联具体课程；记录截止日期与时间、备注和完成状态；自动区分“已逾期”“今天截止”“待完成”“已完成”，并按截止时间排序。
- **本地持久化**：桌面版使用 SQLite（每个账号独立数据库），浏览器版使用 localStorage；支持旧数据迁移、导出 / 导入 JSON 备份、载入示例数据、清空数据。保存失败会提示并保留原状态。
- **设置**：学期名称、第一周起始日（可选任意星期，东北大学通常选第一周的周日）、总周数、每天节次数、各节次起止时间，以及上课前提醒（关闭 / 提前 5 / 10 / 15 分钟）。
- **上课提醒（桌面版）**：软件运行时按设定提前量弹出 Windows 通知，显示课程、教室、节次时间和日期；点击通知打开今日视图，同一节课只提醒一次。
- **开机自启动**：登录 Windows 后静默进入托盘，不弹出主窗口；关闭窗口后提醒继续运行，从托盘退出才彻底停止。
- **迷你悬浮窗**：桌面右下角的置顶小窗，显示正在上/下一节课、开始或下课倒计时、最近待交作业；可拖动位置，点击打开今日视图，并可记住上次是否显示。
- **节次时间同步**：东北大学导入时读取学校作息时间接口，按当前校区自动同步 12 节的起止时间（南湖/浑南上课时间不同）。

## 运行环境

- Node.js 24.15 及以上的 24.x 版本（本机测试使用 24.16.0；当前 jsdom 测试依赖不支持 Node.js 18）
- npm 9 及以上
- 现代浏览器（Chrome / Edge / Firefox 最近版本）

## 安装与启动

```bash
# 进入项目目录
cd coursepilot

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

浏览器打开终端中提示的地址（默认 `http://127.0.0.1:5173`）。

> 请使用**安装了东北大学导入助手的同一浏览器**打开该地址。IDE 内嵌预览、自动化浏览器或另一台机器不会共享扩展，课表页右下角不会出现导入按钮。应用数据按浏览器 origin 保存在 localStorage，建议固定使用 `http://127.0.0.1:5173`，不要混用 `localhost` 和其他端口。

构建生产版本：

```bash
npm run build
npm run preview
```

## 桌面端（Electron）开发

### 开发启动（带热更新）

```bash
npm run electron:dev
```

- 同时启动 Vite（`5173`）和 Electron，修改 `src/` 下的 React 文件会热更新
- 修改 `electron/main.cjs` 或 `electron/preload.cjs` 后，重新执行该命令
- 桌面端本地接口固定为 `http://127.0.0.1:17890`，供东北大学扩展回传；正式版 SQLite 在用户数据目录，桌面热更新开发使用其 `development` 子目录，避免测试覆盖正式数据。网页独立开发仍使用 localStorage，数据可通过 JSON 备份迁移

### 静态桌面运行（不启动 Vite）

```bash
npm run build
npm run electron
```

Electron 自带本地服务器，直接加载 `dist/`，不需要手动启动 Vite；数据保存在 Electron 自己的用户目录，关闭后仍然保留。

### 打包

```bash
npm run electron:build
```

输出 `release/CoursePilot-1.6.2.exe` 便携版，双击即可运行，不需要启动 Vite 或安装 Node.js。修改代码后需要重新打包，旧 EXE 不会自动更新。

### 托盘与关闭行为

- 第一次点击窗口右上角关闭按钮时，会询问“最小化到托盘”还是“退出软件”，并记住选择
- 选择最小化到托盘后，窗口隐藏但程序继续运行，作业提醒照常触发
- 双击托盘图标恢复窗口；右键菜单可“打开主界面”“查看作业”“退出 CoursePilot”
- 点击作业通知会从托盘恢复窗口并进入作业页
- 托盘菜单里的“关闭窗口时重新选择”可以清除已记住的选择，下次关闭重新询问
- 选择“退出 CoursePilot”后进程完全结束，不再触发提醒
- 托盘菜单的“迷你悬浮窗”可以随时显示或隐藏悬浮窗

### 本地账号与数据隔离

- 桌面版首次启动会先显示登录页。创建第一个账号后，升级前已有的课表和作业会自动复制到该账号的数据库中；原数据库仍保留在数据目录里作为一次性备份。
- 每个账号的数据位于 `%APPDATA%/coursepilot/users/<账号ID>/coursepilot.db`；账号列表保存在 `accounts.json`，登录状态保存在 `session.json`。
- 密码使用 scrypt 加盐哈希，不保存明文，也不会离开本机。密码无法找回，请妥善保管。
- 登录状态默认保留；在“设置 → 账号”中退出登录后会回到登录页，可登录其他账号或新建账号。退出登录不会删除任何数据。
- 开发模式的账号和数据库位于 `%APPDATA%/coursepilot/development/`，与正式数据隔离。
- 升级到 1.6.0 并创建账号后，不建议再用 1.5.0 或更早版本修改数据：旧版本读取的是迁移前的旧库，看不到新账号中的变化。

### 开机自启动与迷你悬浮窗

在“设置 → 桌面与启动”中：

- **开机自启动**：开启后，登录 Windows 时会静默启动到托盘，不弹出主窗口；如果上次关闭前悬浮窗是显示状态，会一并恢复。便携版请在固定位置使用 EXE，移动或重命名后重新开关一次。
- **迷你悬浮窗**：在桌面右下角显示当前课或下一节课、开始/下课倒计时、教室和最近待交作业。拖动顶部紫色栏可移动位置，点击内容打开今日视图；右上角按钮可打开主界面或隐藏。关闭后可从托盘菜单再次打开。
- 关闭主窗口选择“最小化到托盘”后，上课和作业提醒继续运行；从托盘选择“退出 CoursePilot”才彻底停止提醒。
- 开机自启动只在打包版可用；开发模式下开关会置灰。

### 作业截止提醒

添加或编辑作业时，可关闭提醒，或选择提前 30 分钟、1 小时、1 天。桌面程序运行期间每 30 秒检查一次；已完成、已过截止时间或已提醒的作业不会重复发送。软件完全退出后不会继续提醒。

便携版首次启动会在当前用户开始菜单创建 CoursePilot 快捷方式，用于 Windows 通知身份注册。请把 EXE 放在固定位置使用；移动后重新运行会更新快捷方式。点击通知会恢复软件窗口并打开作业页。

只有 Windows 返回通知已显示事件后才记录已提醒；发送失败或超时不会记录成功，会在一分钟后重试，并在应用内显示失败提示。通知设置、已提醒记录随本地数据保存。Windows 的勿扰模式、系统通知开关仍可能影响横幅显示，程序不会修改系统设置。

### 上课提醒

在“设置 → 提醒”中选择上课前提醒的提前量（关闭、5、10、15 分钟，默认 10 分钟）。桌面程序每 30 秒检查一次当天课表，到达提醒窗口后弹出 Windows 通知，内容包括课程名、教室、节次时间和日期。点击通知会恢复窗口并打开“今日”页。

- 同一节课只提醒一次，记录保存在设置的 `classReminderLog` 中，随 SQLite 持久化，重启后不会重复提醒。
- 只提醒当天实际发生的课程，已应用周次、单双周和归档状态；停课或非本周课程不会提醒。
- 最小化到托盘后仍会提醒；完全退出软件后不再提醒。
- 网页版不发送系统通知，今日视图仍可正常使用。

## 使用方法

> 桌面版首次启动会先进入登录页。创建第一个账号后，已有课表和作业会自动归入该账号；之后可在“设置 → 账号”退出登录并切换账号。

1. **东北大学一键导入**
   - 首次使用先安装导入助手：打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启“开发者模式”，点击“加载已解压的扩展程序”，选择项目中的 `extension` 文件夹。
   - 在“导入课表”页点击“打开教务系统并导入”，在弹出窗口中完成统一身份认证并进入“我的 → 我的课表”。
   - 点击课表区域右下角的“导入整学期课表到 CoursePilot”。扩展会自动切换到“学期课表”或直接调用课表接口，读取整学期课程并同步学校节次时间；原页面会自动接收并显示预览。若窗口没有反应，可点击“从剪贴板读取”。
   - 在预览中修正内容，选择合并或覆盖，确认保存。
2. **其他导入方式**
   - 登录学校教务系统，进入“课表查询 / 我的课表”页面，等待课程加载完成。
   - 在课表页按 `Ctrl+S`，保存类型选择“网页，仅 HTML”，然后在“导入课表”页上传该文件；
   - 或在课表页右键“查看网页源代码”，复制全部内容，在“粘贴页面源码”中粘贴后点击“解析课表”；
   - 或打开“书签采集”，把“采集课表”按钮拖到浏览器书签栏，在课表页点击书签复制源码，再粘贴到本系统。
   - 预览识别结果并修正错误行，选择“合并导入”或“覆盖课表”，点击“确认并保存”。
3. **设置学期时间**
   - 首次使用请在“设置”中确认“第一周起始日”和总周数。东北大学以周日为一周第一天，请选择第一周的周日（例如 2026-08-30）；课表周次、单双周和列顺序均以此计算。
4. **今日视图**
   - 启动后默认进入“今日”，查看正在上的课或下一节课的倒计时、今日课程状态和最近截止的作业。
   - 点课程行或“完整课表”进入课表页；点作业行或“管理作业”进入作业页。
5. **查看课表**
   - 使用工具栏切换周次；点击课程块可编辑或删除；点击空白格可按对应星期和节次快速新增课程。
6. **管理作业**
   - 在“作业”页新增作业，关联课程并设置截止时间；点击左侧圆形按钮切换完成状态；可按课程和状态筛选。
   - 新增或编辑时可设置“截止提醒”：关闭、提前 30 分钟、提前 1 小时或提前 1 天。
7. **作业截止提醒（桌面版）**
   - 软件运行期间，到达提醒时间会弹出 Windows 通知，显示作业名称、课程和截止时间。
   - 已完成的作业不再提醒；同一条作业提醒一次后会记录 `reminderNotifiedAt`，重启后也不会重复弹。
   - 修改截止时间或提醒提前量会重新允许提醒；只改标题或备注不会重复提醒。
   - 提醒设置和已提醒状态都保存在本地数据中，关闭再打开仍然保留。
   - 最小化到托盘后仍会提醒；从托盘完全退出后不再提醒。
8. **上课提醒（桌面版）**
   - 在“设置 → 提醒”中选择提前量；到时间会弹出 Windows 通知，点击通知打开“今日”页。
   - 同一节课只提醒一次，重启后不会重复；关闭提醒后不再发送。
9. **开机自启动与悬浮窗（桌面版）**
   - 在“设置 → 桌面与启动”开启开机自启动后，登录 Windows 会静默进入托盘。
   - 同一处可显示迷你悬浮窗；也可从托盘菜单“迷你悬浮窗”开关。拖动顶部紫色栏可移动位置。
10. **寻路**
   - 点击顶部导航的“寻路”，会在默认浏览器中打开 `pathly.top`。
11. **备份数据**
   - 在“设置 → 数据管理”中导出 JSON 备份。更换浏览器或清理缓存前请先备份。

## 东北大学一键导入（浏览器扩展）

学校教务系统入口：`http://jwxt.neu.edu.cn/jwapp/sys/homeapp/home/index.html?av=&contextPath=/jwapp#/`（需在校园网或学校 WebVPN 环境下访问；也可从一网通办进入）。

实现方式：纯网页无法读取其他网站的页面内容，因此项目附带一个很小的浏览器扩展（`extension/` 目录）：

1. `manifest.json` 声明只匹配 `*.neu.edu.cn` 与旧版教务地址 `219.216.96.4`，并开启 `all_frames`，因此能注入到教务系统 iframe 内的课表页。
2. `content.js` 判断当前 frame 是否为课表页，是则注入右下角“导入整学期课表到 CoursePilot”按钮。
3. 点击按钮后优先调用教务系统自己的课表接口 `getMyScheduleDetail.do`（POST `termCode`），一次拿到整学期 `arrangedList`，字段包含课程名、星期、节次、周次、教师、教室；同时读取学校作息时间接口 `querySectionInfo.do`，按校区同步节次起止时间。导入完成后请在“设置”中手动确认第一周起始日，应用不会自动覆盖你的选择。
4. 接口返回的`titleDetail`可能含多组周次和教室，需逐条展开，不能只使用概要字段中的第一组。若接口不可用（例如 WebVPN 改写了请求路径），自动回退到“学期课表”div 网格：按星期根列定位星期，优先累计冲突组及并列课程列的`flex-grow`跨度确定节次，配合`data-scales-span`计算跨节数；结构无法识别时才使用卡片坐标回退。
5. 提取结果以结构化数据回传：如果教务页是从 CoursePilot 网页版按钮打开的（存在 `window.opener`），优先通过 `postMessage` 回传给网页版；否则尝试桌面端本地接口 `http://127.0.0.1:17890/api/import`。桌面端也未运行时，扩展会尝试自动打开 `http://127.0.0.1:5173/#import` 并发送数据，同时把 JSON 写入剪贴板作为兜底。
6. 网页版校验 postMessage 来源为东北大学域名，然后进入预览表格；桌面版经本地接口接收。确认后才写入对应存储（桌面为 SQLite，网页为 localStorage）。应用支持 `#today`、`#schedule`、`#assignments`、`#import`、`#settings` 直接打开对应页面。

扩展不读取、不保存账号和密码；课表数据只在本机解析，不会上传到服务器。

> 说明：东北大学课表不是 `<table>`，而是 div 网格，卡片本身不带星期/节次属性，因此扩展在页面内结合布局测量提取。实验课优先读取卡片自身关联的详情；读不到周次、教师或地点时留空提示，不借用理论课安排。缺失周次必须在预览中补充后才能保存。扩展更新后，请在扩展管理页重新加载，再刷新学校课表页面。

提取器回归测试（使用 jsdom 模拟课表网格与元素位置）：

npm run test:neu

测试覆盖：教务接口的多组周次/教室展开、`weeksAndTeachers` 拆分、div网格星期列和结构跨度定位、几何回退、实验课自身详情读取、缺失信息不猜测及告警。另按用户反馈的课程形态检查第12周组原和概率论的五条安排，教师与地点样例使用替换内容。

```bash
npm test
```

包括混合单双周、旧数据兼容、重复与覆盖导入的课程身份、作业关联，以及真实 React 组件在预览、取消、确认时的保存行为。上述测试使用模拟数据，不代表已经通过学校真实登录与导入验收。

学校节次时间只在确认导入时保存，取消或离开预览不会改变原设置。覆盖导入时，同一课程沿用原 ID；本次缺失但仍关联作业的旧课程保留为归档记录，不显示在周课表，再次导入可恢复。

## 课表解析说明

东北大学一键导入使用上文所述的专属 div 网格提取器，不经过本节通用解析器。其他学校的 HTML 课表可使用内置“通用表格解析器”，适用于以“星期一 ~ 星期日”为表头的表格型课表，可识别单元格中的课程名、教师、周次和教室，支持：

- 周次写法：`1-16周`、`1-8,10-16周`、`2-16周(双)`、`3-14周(单)`、`1,3,5周`
- 教室写法：`教1-201`、`计算机楼401`、`理科楼 A305`、`田径场` 等
- 同一单元格内多门课程（使用分隔线或周次行切分）
- 实验课自动标记（课程名或教室包含“实验 / 机房 / 上机”）

解析器位于 `src/lib/parser/`。如学校教务系统使用非表格结构或动态渲染，可在该目录新增专属解析器，并通过 `registerScheduleParser` 注册，无需改动界面代码。

## 数据与隐私

- 课表、作业和设置仅保存在本机：桌面为每个账号独立的 SQLite 数据库，网页为当前浏览器的 localStorage（键名 `coursepilot.data.v1`），不会上传到服务器。
- 桌面版账号信息保存在用户数据目录的 `accounts.json`，密码为 scrypt 加盐哈希；`session.json` 只保存当前登录的账号 ID。网页版不启用登录。
- 页面源码只在本机浏览器内解析。
- 截图或分享时请注意遮挡学号、姓名、账号等个人信息。
- 清理浏览器站点数据会同时清空课表与作业，请定期导出备份；桌面版删除用户数据目录会同时删除所有本地账号及其数据。

## 已知限制

- 通用解析器依赖 HTML 表格结构；纯图片课表、Canvas 渲染或高度定制的前端课表页面无法直接识别。东北大学一键导入已改为专用 div 网格提取，不依赖该通用解析器。
- 东北大学教务系统使用 CSS Modules 的哈希类名，扩展采用包含匹配以降低改版影响；若学校大幅改版导致结构变化，需要同步调整 `content.js` 中的选择器与布局测量逻辑。
- 一键导入优先依赖教务系统内部接口 `getMyScheduleDetail.do`。若学校调整接口或 WebVPN 改写请求路径，会自动回退到 DOM 提取；两条路径都失效时需要更新扩展。
- 东北大学课表页在 iframe 中加载，扩展依赖 `all_frames` 注入；安装或更新扩展后需要刷新已打开的教务系统页面，按钮才会出现。
- 教务系统需在校园网或学校 WebVPN 环境下访问；统一身份认证若启用 COOP 导致回传失败，可使用“从剪贴板读取”作为回退。
- 扩展自动打开的 CoursePilot 地址默认为 `http://127.0.0.1:5173/#import`；如果应用部署在其他端口或域名，需要同步修改 `extension/content.js` 顶部的 `APP_URL` 与 `APP_ORIGIN`。
- 书签采集复制的是完整页面源码，页面特别大时复制和解析会稍慢。
- 不同浏览器、不同设备之间的 localStorage 不互通，需要通过 JSON 备份迁移。
- 单双周与周次范围以“设置”中的第一周起始日为准，学期中途修改会改变已有课程的周次对应关系。
- 桌面版账号只存在本机，忘记密码无法找回；可在删除对应账号数据后重新创建。账号之间不会自动同步数据，需要时使用 JSON 备份导入。
- 网页版没有多用户登录，数据仍按浏览器 origin 保存在 localStorage，与桌面版账号数据不互通。
