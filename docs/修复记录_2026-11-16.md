# 桌面通知与便携版修复

## 问题

- 旧版 EXE 没有包含后来新增的作业提醒功能。
- 主进程调用 `Notification.show()` 后立即报告成功，异步发送失败也可能被记为已提醒。
- 便携版缺少安装程序通常提供的 Windows 开始菜单快捷方式及通知身份注册。

## 修改

- 新增 `electron/notifications.cjs`，等待 Windows 的 `show` 事件才返回成功；处理 `failed`、异常、提前关闭及 10 秒超时。
- 保持通知对象的引用，使通知显示后仍可接收点击事件，退出时释放通知。
- 发送失败不记录已提醒，应用内提示一次，一分钟后重试。
- 写入已提醒记录时检查原截止时间和提前量，避免旧通知结果影响刚修改的提醒。
- 便携版创建当前用户开始菜单快捷方式，使用固定应用 ID；快捷方式指向便携 EXE，而非临时解压目录。
- 点击通知恢复窗口，使用 hash 跳转到作业页，避免依赖 React IPC 监听器的注册时机。
- 重新生成 `release/CoursePilot-1.1.0.exe`。

## 验证

- `npm test`：20 项测试及东北大学提取器测试通过。
- `npm run electron:build`：网页构建和 Windows x64 便携版打包成功。
- 新 EXE 使用独立临时用户数据目录运行，模拟到期作业收到 Windows `show` 回调并保存提醒记录。
- 用户实际确认：“看到了，点击后进入作业页”。这是人工验证结果，非模拟事件测试结论。
- 测试未修改用户原课表和作业数据。

## 使用范围

软件运行时提醒，完全退出后不提醒。Windows 勿扰模式和通知开关仍由用户控制，程序不修改系统设置。
